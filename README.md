# ❌⭕ Tic Tac Toe Game

Hi! I'm **Neha Agrawal**, and this is my Tic Tac Toe Game project, created using HTML, CSS, and JavaScript.

I made this project to practise my web development skills and understand how JavaScript handles game logic and user interactions.

## 🎮 About the Project

This is a simple Tic Tac Toe game where the player plays against the computer.

The goal is to get three of your symbols (X or O) in a row, either horizontally, vertically, or diagonally, to win the game.
## ✨ Features

- Play Tic Tac Toe against the computer.
- Interactive game board.
- Player and computer turns.
- Automatically checks the winner.
- Detects draw conditions.
- Restart button to play again.
- Keeps track of scores.

## 🛠️ Technologies Used

- **HTML** – To create the game structure.
- **CSS** – To design and style the game board.
- **JavaScript** – To handle game logic, player turns, winning conditions, and score updates.
